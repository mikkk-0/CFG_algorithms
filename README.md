### Реализация алгоритма парсинга LR(k)

# Формат ввода
Грамматика подается в виде:<br>
$N_N\ N_T\ N_R$<br>
$A_1\ A_2\ ...\ A_{N_N}$<br>
$b_1\ b_2\ ...\ b_{N_T}$<br>
$rule_1$<br>
$rule_2$<br>
...
$rule_{N_R}$<br>

Где $A_i$ - это список нетерминалов, $b_i$ - список терминальных символов, $rule_i$ - список правил вида $A\ ->\ S_1\ S_2\ ...\ S_n$, $S_i\ =\ A_j$ или $S_i\ =\ b_j$.
Для добавления правила $X\ ->\ \varepsilon$, нужно написать ``X -> ``

# Запуск программы
Для запуска необходимо вызвать ``make lrk``, перед этим добавив нужный тест в папку ``tests`` в файлы ``grammar.txt`` и ``tests.txt``.

# Запуск unit-тестирования

Для запуска тестов необходимо вызвать ``make test``.
